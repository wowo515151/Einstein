Lib4 Public API Inventory

This inventory was generated from the locally inspected Lightlike/Lib4 Python source tree on 2026-11-21. It maps 168 named public methods and properties and seven selected data fields across 28 public classes, plus nine Python operator/call protocol methods, to corresponding JavaScript API names. It also records the two top-level Lib4 exports. The separate instance field map covers the declared and constructor-assigned public fields. It does not copy or execute Python code.

This is a name and surface inventory, not proof of behavioral parity. See the port and test matrix for per-module evidence, intentional differences, numerical limits, and unresolved behavior. In particular, Lib4's Vector4.device and Vector4.dtype expose PyTorch tensor metadata and have no equivalent for JavaScript number arrays. RelativityContext.device is only a descriptive setting and does not transfer arrays to a device.
