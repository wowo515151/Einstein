Third-Party Code and Provenance

This page records the local files reviewed for this project. It does not establish rights for material whose provenance or license remains unresolved.

ThreeViz core

src/three-viz/ contains the 27 files from the local 3DViz project's library/three-viz/src/ tree. The source project's index identifies the repository-root license as MIT; the copied notice is THREEVIZ-LICENSE. In the local audit on 2026-11-21, the source and copied notices had identical SHA-256 hashes, and all 27 source files were present with no extra files. Two files differed from the local source snapshot because of project changes:

  • src/three-viz/core/mount.js: selection gesture handling, render-failure propagation, and update-error callback context for suppressing stale status messages.
  • src/three-viz/plotters/point-cloud-plotter.js: selectable point data and update rollback behavior.

The rest of the core was byte-identical to the local source at that audit. This statement describes that comparison date, not future changes.

Lib4

The JavaScript library implements mathematical behavior from the inspected local Lib4 package; Python source and bytecode are not copied into this repository. No license file was found in the inspected Lib4 directory or in a filename search of its parent Lightlike tree. On 2026-11-21 the project operator confirmed they authored Lib4 and authorized its use for Einstein. The MIT license in this repository applies to the Einstein project files; it does not purport to relicense or include the Python source. Method-level behavior claims remain limited to the evidence in the port matrix.
